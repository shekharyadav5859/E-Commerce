# S-Kart

S-Kart is a modern and responsive e-commerce web application built with React.js. It provides users with a smooth shopping experience including product browsing, search, categories, cart management, user authentication, address management, and order tracking.

## Features

* Browse products
* Search products
* Browse products by category
* Responsive design
* Add products to wishlist
* Add products to cart
* Increase or decrease product quantity
* Calculate cart total
* User signup and login
* Manage delivery address
* Place orders
* View order history
* Toast notifications
* Infinite product loading

## Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Tailwind CSS
* React Router
* Lucide React
* React Toastify
* REST API
* LocalStorage
* Vite

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project directory:

```bash
cd S-Kart
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## Main Functionality

### Authentication

Users can create an account and log in using their credentials.

### Product Search

Users can search for products and browse products by different categories.

### Shopping Cart

Users can add products to the cart, update product quantities, and view the total cart amount.

### Address Management

Users can save their delivery address and use it during the checkout process.

### Orders

After completing the checkout process, the order is saved and can be viewed from the user's order section.

## Responsive Design

S-Kart is designed to work on desktop, laptop, tablet, and mobile devices.
